# ИИ-МУЛЬТСТУДИЯ: модели, компьютеры и запуск через GitHub
**Версия: 16 октября 2026 г.**  
**Назначение:** рабочая инструкция по созданию художественных 2D/3D-мультфильмов на облачных GPU.

## 1. Короткий вывод
Домашний ПК (Intel 12-го поколения, 16 ГБ RAM) можно использовать для сценариев, подготовки рисунков, браузера, загрузки файлов и монтажа лёгких проектов. Для локальной тяжёлой видеогенерации важна **видеопамять NVIDIA GPU (VRAM)**. Вместо покупки дорогой станции — аренда GPU в облаке по мере необходимости. **GitHub — хранилище программ, а не сервер для запуска тяжёлой генерации.**

## 2. Термины
- **RAM** — обычная оперативная память компьютера.
- **VRAM** — память видеокарты; именно её часто не хватает моделям.
- **GPU** — видеокарта, выполняющая вычисления нейросетей.
- **Репозиторий GitHub** — код и инструкция установки; для запуска могут отдельно понадобиться веса модели и принятие лицензии.
- **VPS без GPU** — подходит для сайта или бота, но не для тяжёлой генерации видео.
- **Облачный GPU-сервер** — арендованный компьютер с видеокартой NVIDIA.

## 3. Открытые модели и GitHub
### 3.1 LongCat-Video / Avatar
**Задача:** анимация говорящих героев по аудио, синхронизация губ; семейство также поддерживает видеогенерацию. **Для планирования** рассматривать GPU с 80 ГБ VRAM, но точная потребность зависит от сценария, разрешения и оптимизаций; это не универсально доказанный минимум.
GitHub: https://github.com/meituan-longcat/LongCat-Video

### 3.2 ToonCrafter
**Задача:** рисованная 2D-анимация между заданными начальным и конечным кадрами. Официальный репозиторий сообщает около **24–27 ГБ VRAM** в исходной реализации; сторонние оптимизации доходят приблизительно до 10 ГБ. Исходная демонстрация работает с короткими фрагментами до 16 кадров и 512×320, то есть это не самостоятельный генератор длинного мультфильма.
GitHub: https://github.com/Doubiiu/ToonCrafter

### 3.3 HunyuanVideo-Avatar
**Задача:** видео персонажа с речью и мимикой. Требования меняются с режимом и оптимизациями; выбирать GPU после прочтения актуального README конкретной версии.
GitHub: https://github.com/Tencent-Hunyuan/HunyuanVideo-Avatar

### 3.4 HunyuanVideo 1.5
**Задача:** генерация видеосцен из текста и изображений. Официальный минимум: **14 ГБ VRAM при включённом offloading** (переносе части данных из видеопамяти). Требуются Linux, NVIDIA/CUDA, Python 3.10+.
GitHub: https://github.com/Tencent-Hunyuan/HunyuanVideo-1.5

### 3.5 HunyuanVideo-I2V
**Задача:** оживление исходной картинки. Для крупных старших моделей могут требоваться GPU класса 60–80 ГБ; проверять требования конкретной конфигурации, не переносить автоматически цифры между версиями.
GitHub: https://github.com/Tencent-Hunyuan/HunyuanVideo-I2V

### 3.6 Index-AniSora (Bilibili)
**Задача:** генерация аниме и художественной рисованной анимации. В репозитории представлены разные версии; GPU-требования нужно сверять для выбранной папки/модели. Официальный GitHub (правильный регистр имени не принципиален):
https://github.com/bilibili/Index-anisora

### 3.7 ComfyUI
**Задача:** визуально соединять модели и действия в единый процесс. **Это интерфейс, а не модель.** VRAM зависит от подключённых генераторов.
GitHub: https://github.com/Comfy-Org/ComfyUI

## 4. Инструменты, которые не следует путать с открытым запуском из GitHub
Runway, Kling, Google Flow/Veo, коммерческие версии Seedance и Higgsfield обычно используются через облачный продукт или его API. Наличие связанных GitHub-проектов **не означает**, что веса их закрытых моделей можно самостоятельно развернуть на Vast.ai.

## 5. Требования к компьютеру
### Домашний ПК
Имеющийся Intel 12-го поколения и 16 ГБ RAM подходят для браузера, текстов и управления облачной студией. Для комфортной локальной обработки/монтажа желательно повысить RAM до 32 ГБ, если есть возможность, но покупать дорогостоящую GPU заранее не нужно.

### Облако — начальный профиль
- GPU: NVIDIA RTX 4090 / 24 ГБ VRAM.
- RAM: 32–64 ГБ, CPU: около 8 виртуальных ядер.
- SSD: 200–500 ГБ, Linux Ubuntu, совместимые версии Python/CUDA.
- Подходит для изучения ComfyUI, HunyuanVideo 1.5 с offloading и оптимизированных моделей. ToonCrafter в стандартной конфигурации может не помещаться стабильно в 24 ГБ.

### Облако — тяжёлый профиль
- GPU: NVIDIA A100 или H100 с **80 ГБ VRAM**.
- RAM: 64–128 ГБ, CPU: ориентировочно 16 виртуальных ядер.
- SSD: 500 ГБ – 1 ТБ, Linux Ubuntu.
- Рассматривать для LongCat Avatar и требовательных видеосцен после сверки README.

**Важно:** объём CPU/RAM/SSD — практические ориентиры аренды, не официальные минимумы каждой модели. Некоторые модели требуют более одной GPU либо специальных версий драйверов.

## 6. Где арендовать GPU
1. Vast.ai — https://vast.ai/
2. RunPod — https://www.runpod.io/
3. Lambda — https://lambda.ai/

Перед оплатой проверить: видеокарту и VRAM, доступность места на диске, цену с учётом хранения, загрузку весов, разрешённые порты, образ CUDA, лицензию модели и возможность остановить/удалить экземпляр.

## 7. Порядок запуска
1. Выбрать **одну** модель и открыть её официальный GitHub.
2. Прочитать README, лицензию, требования к GPU, инструкции скачивания весов.
3. Выбрать подходящий облачный сервер: сначала 24 ГБ для лёгкого теста, 80 ГБ — для тяжёлой модели.
4. Развернуть Linux-окружение, установить зависимости строго по README.
5. Скачать веса с указанного разработчиком источника.
6. Запустить короткий тест: 1 персонаж, 1 действие, низкое разрешение.
7. Проверить расход VRAM, качество и стоимость одного ролика.
8. Скачать исходники и результаты на свой ПК / в хранилище.
9. Остановить или удалить инстанс, чтобы избежать лишних начислений.

## 8. Рекомендуемый процесс создания мультфильма
Сценарий → лист персонажа и референсы → раскадровка → генерация ключевых изображений → короткие анимационные фрагменты → мимика/речь → монтаж и звук → экспорт. Сохранять референсы, промпты, версии моделей и исходники по папкам, чтобы персонаж не менялся между сценами.

## 9. Как организовать папку проекта
```text
multstudio/
  README.md
  characters/
  prompts/
  storyboards/
  audio/
  renders/
  notes/
```
Не загружать в публичный GitHub секретные API-ключи, личные данные, чужие защищённые материалы без разрешения или большие файлы весов. Для тяжёлых видео и весов — отдельное хранилище.

## 10. План первого эксперимента
**Первый тест:** арендовать RTX 4090 24 ГБ и проверить HunyuanVideo 1.5 в доступной оптимизированной конфигурации; отдельно проверить ToonCrafter при подходящем профиле VRAM. **Второй тест:** запустить LongCat Avatar на 80-ГБ GPU, когда будут готовы изображение героя и аудио. Сравнить движение, сохранение внешности, время и стоимость. Не покупать физический компьютер до измерения этих показателей.

## 11. Предостережения
- Не считать GitHub облачной видеокартой.
- Не путать RAM и VRAM.
- Уточнять версию модели: требования могут существенно различаться.
- Учитывать коммерческие ограничения лицензий, особенно если мультфильмы будут монетизироваться.
- Не ориентироваться только на обещания сторонних сайтов: первоисточник — README и модельная карточка разработчика.
